# Susejing Gallery

Galería multi-fuente de imágenes para **Kino** (Safe / 18+).

## Instalación

**Ajustes → Plugins → +**

```
Susejing/Susejing-Gallery
```

## Funciones (v0.2.0)

- Pestañas **Safe** y **18+**
- Fuentes: Safebooru, Konachan, Wallhaven · Yande.re, Danbooru, Gelbooru
- Búsqueda por tags
- Grid + detalle (abrir original, favoritos, copiar tags)
- **Favoritos** guardados en el aparato
- Paginación: Anterior / Siguiente / Cargar más
- «Usar como tema»: Kino no puede aplicar imágenes online como tema de la app; se explica y se abre el original

## Notas

- Algunas miniaturas de Wallhaven pueden fallar (candado / vacío).
- Favoritos usan `kino.storage` (por aparato).
