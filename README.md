# Susejing Gallery

Galería multi-fuente de imágenes para **Kino**.

Elige entre fuentes Safe y 18+, cambia de sitio (Safebooru, Konachan, Yande.re, Danbooru, Gelbooru, Wallhaven…) y busca por tags.

## Instalación

En Kino: **Ajustes → Plugins → +** y escribe:

```
Susejing/Susejing-Gallery
```

(o la dirección del repositorio donde lo publiques).

## Fuentes actuales (v0.1.0)

**Safe**
- Safebooru
- Konachan (safe)
- Zerochan (básico)
- Wallhaven (SFW)

**18+**
- Yande.re
- Konachan (r18)
- Danbooru
- Gelbooru

## Uso

1. Abre **Gallery** desde el menú de Kino.
2. Cambia entre pestañas **Safe** / **18+**.
3. Elige la fuente con los chips.
4. Escribe tags y pulsa buscar.
5. Toca una imagen para verla más grande.

## Notas

- Primera versión funcional. Zerochan y algunas APIs pueden necesitar ajustes.
- Gelbooru a veces exige API key para más volumen (se puede añadir en ajustes más adelante).
- El diseño se irá puliendo.
